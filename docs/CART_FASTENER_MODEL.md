# 小车螺丝：受力模拟与外观标准化说明

当前采用简化螺纹力学模型：用力和力矩约束螺丝的旋转、退扣与取出，不计算真实螺纹牙面的接触。外观来自视频观察和机械常识补全，尚未按 GB/T、ISO 或具体厂商紧固件规格建模。

需要区分两个版本：**旧版已在 Isaac 中运行一枚螺丝的旋松实验；最新整车资产完成了8处连接的几何修复，尚未把这些新连接接入拆卸动力学。** 爆炸图展示的是最新资产的零件布局。

## 1. 螺丝如何模拟受力

主要代码为 `experiments/cart_assembly/mechanics.py`，旧版整车实验由 `experiments/cart_full/connection.py` 调用。

每个仿真步读取螺丝刚体的实际姿态、速度和位移，计算沿轴累计转角 θ 与退出距离 z。设导程为 p，每弧度的轴向行程 h=p/(2π)，用弹簧阻尼维持螺旋关系：

```text
理想退扣关系：z = hθ
耦合轴向力：Fz = -k(z - hθ) - c(vz - hω)
对应反力矩：τthread = -hFz
```

这使螺丝转动时沿轴退出，提前拉拔则受到耦合阻力。横向弹簧阻尼和倾斜恢复力矩近似螺纹孔的导向作用。运动由物理引擎积分，运行过程中不直接写入螺丝位置或转角。

工具通过理想传矩接口施加力矩：未啮合或工具通道被挡时，不传递工具力矩。低速时加入松脱阈值，转动后加入运行阻力和角阻尼；初始座面设置单向止挡，阻止继续向里拧。该止挡不模拟预紧力增长或拧坏。

达到声明的啮合退出长度后，撤销螺旋耦合、横向及倾斜导向，再用轴向拉力取出。状态依次记录为“夹紧、旋松、松动但仍啮合、脱扣、取出”；其中“夹紧”只是状态名称，**当前并没有计算真实的夹紧预载荷**。

旧版实验参数如下，全部为假设值：

| 参数 | 数值 |
| --- | --- |
| 导程 | 0.8 mm/圈 |
| 初始有效啮合长度 | 4 mm |
| 低速松脱阈值 / 运行阻力矩 | 0.002 / 0.0008 N·m |
| 轴向耦合刚度 / 阻尼 | 2000 N/m / 5 N·s/m |
| 工具输入力矩 / 脱扣后拉力 | 0.004 N·m / 0.08 N |

因此约5圈脱扣是上述参数的结果，不是从视频测得的行为。实验将车体固定为夹具并关闭重力，反力由固定夹具承担；没有验证自由车体的反作用、工具打滑、被连接件承载或松开后的横梁释放。旧版质量与惯量也是独立实验参数，未按实物辨识，不能据其运动时间预测真实拆卸速度。

## 2. 外观是否遵循标准

**目前没有对应到某个确定的标准件型号。** 没有把它认定为 M4、#8-32，也没有核实头型、工具规格、公差、强度等级或表面处理。0.8 mm导程同样不是由当前杆径推导出的标准螺距。

最新资产使用以下简化几何，尺寸均为建模假设：

| 部件 | 当前表示 |
| --- | --- |
| 螺钉头 | 直径7.2 mm、厚2.8 mm的圆柱 |
| 螺杆 | 直径3.8 mm的光滑圆柱；四角长10 mm，支架长12 mm，前梁长56 mm |
| 工具凹槽 | 头部深色六边形表面标记，未做真实凹槽和啮合接触 |
| 垫圈 | 外径9 mm、孔径4.4 mm、厚0.8 mm的贯通圆环 |
| 螺母 | 外径8 mm、孔径4 mm、厚3.2 mm的贯通圆环；未建六角扳手面和牙型 |

这些部件遵循的是基本装配关系：螺杆穿过真实孔道，头部及垫圈覆盖孔边，长度覆盖夹紧层并到达螺母，背面需要反扭矩保持。**几何相容不代表符合制造标准或足以承载。** 新增螺母、垫圈及背面结构均保留为可替换的推断。

## 3. 最新资产与 Harness 的关系

`experiments/cart_full/repair_fasteners.py` 修复本车连接，`harness/assembly.py` 检查杆件避碰、夹紧层叠、有效啮合长度、紧固件外形碰撞及直线工具通道。失败结果反馈给几何修复循环；图像引用、候选假设、修改依据和报告哈希一同保存。

本轮8处连接通过当前几何检查，前部4处仍依赖先移除上层横梁，背面扳手操作未验证。新资产中的长螺栓/螺母方案不能直接沿用旧版固定螺纹座的5圈脱扣结论。后续需要给新连接建立独立刚体和可释放约束，再验证预紧、保载及连接解除。
