# 机械资产标准草案 v0.1

2026-11-13 · 待人工复审

本标准用于从图片、视频或已知规格生成可重组的 Isaac Sim 资产。重建结果保留观察到的外形、分件和装配状态。标准件库提供可以替换的局部机械结构。一个场景可以由同一份重建结果派生出不同尺寸、阻力或初始装配状态的版本，供下游机器人探索。

首版覆盖七类刚体结构。弹簧、弹性卡扣、柔性物体在本版范围之外。磁吸可作为通用连接的等效保持力，记录作用方向、有效范围和释放条件，继续使用宿主的几何与接口。

## 1. 资产和接口怎么定义

沿用 `AssemblyBlueprint`。同一零件定义可以在多个装配中实例化，也可以被接口兼容的其他定义替换。

| 层级 | 沿用字段 | 最小约定 |
| --- | --- | --- |
| 零件定义 | `part_definitions`、`spec_ref` | 稳定 ID、本地坐标系、外形描述、构建所需的尺寸及物性来源。可复用规格使用带版本的 `spec_ref`。普通杯身、盖板、外壳等可只定义自身几何和接口。 |
| 零件实例 | `part_instances`、`states.part_poses` | 实例引用零件定义，在状态中保存摆放位姿。能独立取下、换件或运动的构件有独立实例及对应的 USD 零件身份。 |
| 接口 | `interfaces` | 稳定 ID、所属实例、几何类型、零件本地坐标系中的位置与方向、带单位的关键尺寸。可定位但缺尺寸时，保留接口和缺失字段。 |
| 连接 | `mates`、`rule_ref`、`joints` | 明确绑定两端接口，记录规则版本、允许的自由度、配合间隙、限位或释放条件。可独立替换的零件依靠接口重新配对。 |
| 装配状态 | `states` | 记录当前零件位姿、关节位置和生效的连接。夹紧、松动、锁住、脱扣等状态由连接规则解释，并明确是否仍存在其他接触或约束。 |

几何尺寸使用 m，内部角度使用 rad，质量使用 kg，力使用 N，力矩使用 N·m。蓝图和生成物沿用 Z-up。轴向接口注明正方向、零位和止挡基准。带旋向的连接需写明从哪一端观察，以及旋转正方向对应的轴向位移方向。单位转换由 USD 写入层统一完成。 [OpenUSD 物理单位与关节坐标系](https://openusd.org/release/api/usd_physics_page_front.html)

首版接口按几何可复用为安装面／止挡面、圆柱外径／孔径、内外螺纹、导轨截面、球面／球座、卡爪／入口槽／锁止槽。接口可直接建在重建网格对应的宿主上。把手等造型也可以作为宿主几何的一部分，随该刚体传力。

**可替换条件。** 比较的是实际配对接口的类型、尺寸、局部方向和必要的止挡。更换零件后重新求装配位姿，并检查外形与周边的干涉。例如同规格螺钉可有多种杆长，每种杆长都要重新检查孔深、夹持厚度和有效啮合。一个接口的名字相同，只表示它在装配中承担同一个角色。

## 2. 七类结构的规格

下表列出构建所需的最少信息。某些字段可由规格表或已有几何导出。观察阶段可保留未知，进入构建阶段时所用的值必须明确。

| 类别 | 构建所需的参数和接口 | 配合和物理规则 | 示例 |
| --- | --- | --- | --- |
| **1. 螺纹件** | 螺纹直径、导程、旋向、有效长度。螺钉另有杆长，头部有操作需求时定义头型及批头接口。宿主分别声明通孔和内螺纹。 | 通孔检查杆径与孔径。内外螺纹检查直径、导程、旋向、深度与有效啮合。按导程耦合转角与轴向位移。预紧力、起拧力矩、续拧力矩及预紧卸载行程属于连接。 | 螺钉盖板、带螺纹嵌件的壳体、螺纹杯盖 |
| **2. 轴** | 轴线、端面基准、参与配合的各段直径与长度。轴向定位依靠轴肩或端面时，记录该位置。 | 每个配合轴段与对应孔同轴，核对径向配合和轴向重叠。连接可固定、单轴转动，或允许轴向滑动。限位及轴向保持由与对端的配合决定。 | 铰链轴、轮轴、旋钮轴 |
| **3. 轴承与轴套** | 内侧接口直径、外侧安装尺寸、宽度、共同轴线和安装端面。外侧可采用座孔、法兰或其他明确的安装面。 | 分别检查轴与内侧、外侧与座的两个配合。首版可让轴相对支承转动，轴向约束用轴肩、端面或连接参数表达。转动阻力和载荷方向在有需要时由配合声明。 | 独立轴承、轴套、带座支承 |
| **4. 插销** | 插入段直径和长度、对端孔径和孔深、插入方向、到位基准。需要主动解锁时声明对应接口。 | 核对插入间隙和到位深度。记录插入、到位保持、解除保持、退出。保持可以来自刚性限位、外部解锁条件或指定拔出阻力。允许退出时要检查拔出通道。 | 定位销、可拔插销、刚性锁销 |
| **5. 导轨与滑块** | 导向轴、两端截面或简化包络、有效啮合长度、行程零位与端点。声明滑块是否允许越过指定端点脱离。 | 检查截面兼容、间隙、啮合和止挡。用直线关节表达导向，记录滑动阻力。可抽离型在脱离条件满足后释放约束并保留独立刚体。 | 抽屉滑轨、滑盖、可抽离托盘 |
| **6. 球头与球窝** | 球心、球径、球窝位置及容纳范围、开口方向和球颈净空。记录初始朝向及摆动范围。 | 对齐球心，检查球窝配合及球颈与开口的干涉。用球形关节表达多方向转动。若需独立的自旋限位、锁紧或可拆规则，作为连接扩展明示。刚性可拆型须给出几何退出路径。 | 手机支架、可调节支座 |
| **7. 旋转卡口** | 两端公共轴线、插入定位角、插入深度、锁定角、卡爪与入口槽的数量、角位置及尺寸。必要时补充锁止槽深度和止挡面。 | 对准入口后轴向插入，到位后旋转至锁定角。锁定时限制轴向退出，回到允许退出的角度后解除保持。首版用刚性槽口、限位和状态规则表达。 | 杯身与旋扣杯盖、瓶罐盖、外壳与可旋装模块 |

### 螺纹和旋转卡口的状态

- **螺纹**。由已夹紧进入松动且仍啮合，再进入脱扣。单线螺纹的名义脱扣圈数为有效啮合长度除以导程。运行时应同时考虑净转角和实际轴向位移。脱扣表示这条螺纹连接解除，是否已从其他孔或槽完全取出由另一个几何条件记录。首版使用光滑螺杆与孔道加等效导程约束。
- **旋转卡口**。用 `分离 → 对准并插入 → 转至锁定 → 旋回退出角 → 拔出` 表达。插入阶段记录允许进入的角度范围，转动阶段记录需要先达到的轴向深度，退出阶段同时检查角度和退出路径。若结构另有刚性止挡或独立解锁件，由单独的连接记录约束。日常实物参考可见镜头和遮光罩的安装步骤。 [尼康安装说明](https://onlinemanual.nikonimglib.com/z7_z6/en/14_technical_notes_07.html)

**旋转卡口是宿主结构的一部分。** 一个旋扣杯由杯身和盖子两件刚体组成，杯口带入口槽和锁止槽，盖子带卡爪。Agent 保留重建的杯体和盖体外形，只对配合区域应用卡口规格。带连续螺纹的杯盖匹配螺纹规则，直接套合的盖子使用相应的接触或插接关系。

## 3. 数值和重建证据

- **几何与配合尺寸。** 先使用已测量的数据和匹配的规格表。视角可支持粗估时记录 `estimated` 及来源。不可见的内孔深度、卡口内部槽形等可保留 `unknown`。已有米制蓝图可通过 `propose_build` 补充允许的未知尺寸、质量、行程与零位，假设绑定原蓝图。接口和结构变化走结构修订。相对宽度坐标转入米制构建时需独立确定尺度。
- **力与力矩。** 区分承载上限、启动阻力、运动中阻力和脱离阈值。需要某个值时写清作用方向或参考轴、作用点及触发后的变化。Astra 可以填写名义值或明确的随机化范围，保存为仿真假设。标为 `measured` 的数值绑定测量证据。`Parameter.interval` 用于记录估计区间，批量生成的采样范围单独记录。
- **结构假设。** 如果只观察到转轴和旋转，蓝图可以记录旋转关系，轴承种类保持未知。选用某个轴套或轴承生成的版本，要把所选规格和新增几何标为构建假设，并与原重建记录关联。

## 4. 接入现有 Agent Workflow

| 现有阶段 | 本标准在该阶段的职责 |
| --- | --- |
| **Perception / Evidence** | VLM 提供对象和局部结构线索，SAM 提供遮罩。保留能支撑分件、尺寸或运动判断的原始视图。背景按现有独立路径处理。 |
| **AssemblyBlueprint / 结构审核** | DSH Agent 选择分件与结构假设，标注接口，提出 `spec_ref` 和 `rule_ref`。已知规格输入可以直接填充同一种蓝图。独立审核核对证据、歧义和候选解释。 |
| **结构前检 / `compile_mates`** | 按规格和规则版本检查两端类型、尺寸、方向和必要参数。规格不匹配、关键数值缺失或后端能力未接入时，回到结构、证据或构建假设阶段。 |
| **`GeometryRecipe` / 几何审核** | 把接口绑定到实际基元或网格生成区域，检查局部对齐、间隙、轴向重叠、运动空间和脱离路径。Critic 记录失败的接口、数值和修订范围。 |
| **Blender / OpenUSD** | Blender 生成分件视觉网格和碰撞几何。OpenUSD 写入刚体、关节、连接绑定及初始状态。等效螺纹、可脱离导向、旋转卡口等需要运行时切换约束的关系，随交付包记录所需的 Isaac 运行时能力。 |
| **候选交付 / 后续验收** | 场景包保存 USD、蓝图、规则版本、初始状态和来源。几何审查与物理验收分别记录。机器人行为由下游记录，不参与资产规格的分类。 |

当前源码已具备蓝图结构、几何审核、`compile_mates` 入口、M3/M4/M5 声明式螺钉盖板和限位铰链生成代码。螺纹盖板的运行时钩子需由接收端挂载，行为待 Isaac 验收。轴、轴承／轴套、插销、导轨／滑块、球头／球窝与旋转卡口的专用规格和规则仍是本草案的设计内容。现有轴孔或通用关节表达可复用。球形关节、旋转卡口及连接力学参数的场景变体仍需接入蓝图和构建层。媒体构建仍受现有后端投影支持范围约束。 [当前装配蓝图](ASSEMBLY_BLUEPRINT.md) · [几何审核](MECHANICAL_GEOMETRIC_VERIFICATION.md) · [Isaac USD 工作流](ISAAC_USD_WORKFLOW.md)

## 5. 人工复审项

1. **轴、轴承与插销。** 复审哪些零件族共用圆柱段参数，以及轴向保持默认由哪一个端面或接口声明。
2. **导轨与球窝。** 复审首批几何采用哪些截面和开口，哪些构型允许整件抽离或拆出。
3. **杯体类卡口。** 复审先采用哪一种卡爪与旋槽形状，以及锁定角、锁止深度和退出角是否足够表达首批样件。
4. **力学参数。** 复审哪些参数由规格固定，哪些由用户声明、由 Astra 填写名义值，或在场景变体生成时采样。
