# 自动生成机械结构：相关论文与当前能力

检索日期：2026-10-26 至 2026-10-27。围绕本仓库的目标：从真实视频和语言恢复零件、装配和功能，生成供机器人使用的物理资产。以下依据论文原文、正式论文集和作者项目页；未复现这些论文的实验。预印本与已发表工作分别标注，不把作者声明视作独立验证。

目前已有方法生成可编辑 CAD 零件、分件网格、运动关节和一部分经过功能测试的机械装配。对本次自行车任务，仍没有在本次检索中找到充分证据，证明已有通用系统能仅凭未拆解的普通外观视频，准确恢复全部螺钉、轴承、锁止和制动内部件及其尺寸、公差，同时保证装配和动力学正确。

这个缺口包括观测本身的歧义：两个轮毂可以具有相同外壳、不同轴承和制动结构。更多外观视角可以减少遮挡，但无法直接观测始终被不透明壳体包住的内部件。基于常识生成一个合理结构，与辨识出这辆实车的真实结构，需要分别记录。

**最接近当前目标的工作**

| 论文与状态 | 方法、输入与输出 | 对本项目的意义及边界 |
| --- | --- | --- |
| [FunCAD-Harness / Can It Actually Work?](https://arxiv.org/abs/2610.26861)，2026-10-19 预印本 | 从功能描述构建 CAD；将固定功能测试绑定到候选机构，使用物理反馈反复修改 | 与后续功能 harness 最接近；研究设计新机构，不是从照片完整恢复特定实物 |
| [AssemCAD](https://arxiv.org/abs/2607.05123)，2026-07 预印本 | 类型化零件、几何接口 ports、装配约束 mates、工程规则；确定性 CAD 内核构造与检查 | 适合研究轴—轴承—支座、紧固件、齿轮的装配表示；不能将标题的 production-ready 理解为已经验证制造公差和寿命 |
| [SPADA](https://proceedings.mlr.press/v306/zheng26q.html)，ICML 2026 | 参数化装配代码与确定性测试共同生成，执行编译—测试—修复 | 可参考把要求写成可执行契约；本次仅核对官方摘要，未取得全文，不引用具体成功率 |
| [Procedura](https://arxiv.org/abs/2608.26238)，2026-08 预印本 | LLM 写命名零件和 typed mates；由配合坐标求放置，逐件检查编译、接口和连通性；视觉审阅修正 | [开源代码](https://github.com/SpatiaOS/Procedura)输出 OpenSCAD、OBJ，以及运动部分的 USD/URDF；适合替代手填坐标式装配。项目展示的摩托车为 19 个模块，不能等同于制造级完整 BOM |
| [Artisan](https://arxiv.org/abs/2610.13947)，2026-10 预印本 | 文字与可选参考图 → Design/Coding/Review → 物理仿真反馈；包含质量、材料、碰撞与重力稳定性 | 与本仓库已有依赖直接对应；侧重机器人可用资产，不能推出隐藏机械结构已完整恢复 |

FunCAD-Harness 的原文尤其值得读。其环境使用 Project Chrono 与 Bullet，允许声明的等效机构，并用功能测试及源几何检查约束结果。46 个任务族中，默认单次配置最高完成 32/46；自行车在四种默认配置下均无完整通过记录。每次尝试允许三小时主动工作，包含内部修改；“单次”不是一次模型回答。论文还展示了少量打印原型，但没有对整个基准进行制造验收。[正文 §3–5、附录 E](https://arxiv.org/html/2610.26861v1)

AssemCAD 的验证范围也需读清。论文把 production-ready 限定为可执行、结构连通、接口有效、无非预期几何干涉，不包含完整制造工艺、材料和公差分析。AssemBench 有 120 个装配实例，平均 3.38 个 bodies、4.52 个 occurrences、2.23 个 joints。其 APR 使用 LLM 代码裁判，不能直接解释为真实机器功能成功率。这支持“小规模受约束装配生成已有进展”，不足以证明整车精密逆向工程已解决。[正文脚注 1、§5、附录 F](https://arxiv.org/html/2607.05123v1)

Artisan 的本机来源已核对：`/home/felixz/real2sim/R2S2B/sources/Artisan/README.md` 链接论文 2610.13947 和 `physicalvision/Artisan`。论文的 Design/Coding/Review 与仿真反馈可以作为本仓库现有资产构建的参考；本仓库已经完成哪些实验仍应依据自己的运行记录，而不是继承论文整体结论。[作者项目页](https://physicalvision.github.io/artisan/)

**从图像恢复零件和运动，目前做到哪里**

| 工作 | 已展示的内容 | 对自行车精密结构的限制 |
| --- | --- | --- |
| [PartCrafter](https://wgsxm.github.io/projects/partcrafter/)，NeurIPS 2025 | 单图条件下，以组合潜空间和局部/全局注意力生成多个独立网格；包含不可见部分的先验补全 | 可拆分的语义部件不是制造 BOM；不保证螺钉数量、轴孔配合或隐藏件真实。项目明确报告实拍图与训练渲染图存在域差异 |
| [Real2Code](https://arxiv.org/abs/2406.08474)，ICLR 2025 | 视觉分割、形状补全与零件包围盒，经代码模型预测关节；可结合多视角 RGB 重建 | 展示最多 10 个可动部件；其“部件”主要是运动 links，并非把每个紧固件拆出来 |
| [Articulate-Anything](https://articulate-anything.github.io/)，ICLR 2025 | 文字/图像/视频 → 网格检索 → VLM 生成 Python/URDF → actor–critic 修正 | 很适合研究关节推断和审阅流程；检索和关节恢复不能代替实车隐藏件识别 |
| [LAM](https://gaoypeng.github.io/LAM/)，CVPR 2026 | 文字 → 部件层级 → 几何与关节代码，配合检查器迭代；无需预制资产 | 支持从零生成可动结构；如多按键键盘仍不能证明复杂传动与所有内部制造件均准确 |
| [PhysX-Anything](https://physx-anything.github.io/)，CVPR 2026 | 单张自然图像 → VLM 物理表示 → 几何细化 → 可仿真资产；展示仿真中的机器人策略学习 | 强于只生成外观；图像推断的物理属性仍需实测校准，不是材料/质量真值 |
| [PhysX-Omni](https://arxiv.org/abs/2605.21572)，2026-05 预印本 | 将生成范围扩展到刚性、可变形、可关节化资产；评估尺度、材料、运动和功能描述 | 覆盖更广的资产类型，不等于精密机械内部恢复 |
| [Track, Articulate, Act](https://arxiv.org/abs/2609.19119)，2026-09 预印本 | 用单目交互视频中的稠密三维点轨迹估计 links、关节及状态轨迹 | 对后续“拍人实际操作物体”很有用；需要可观测运动，绕静止自行车拍一圈不能提供同等关节证据 |

在这些路线里，VLM 用于结构语义和代码；SAM 类模型用于可见区域分割；多视角几何或三维跟踪用于位置与运动证据。COLMAP 和 3DGS 可支持相机、可见表面及外观对照，但不会因为重建更精细就自动获得内部轴承、螺纹和真实传动参数。后者需要额外证据和结构约束。

**精密 CAD、真实装配和机构功能是三个不同的问题**

- [CAD-Recode](https://cad-recode.github.io/)（ICCV 2025）把点云译成可执行 CadQuery 代码；[cadrille](https://arxiv.org/abs/2505.22914)扩展到图像、点云和文字。适合研究零件级参数化重建；不是整机隐藏 BOM 恢复。
- [JoinABLe](https://karlddwillis.com/joinable/)（CVPR 2022）基于给定的实体零件，预测配合面/边、关节轴和相对姿态。它的前提是零件几何已存在，可以用于后续装配关系推断。
- [Assemble Them All](https://assembly.csail.mit.edu/)（SIGGRAPH Asia 2022）从已知装配态和分件几何求拆卸路径，再反向得到装配序列，展示过 80 件装配体。它解决的是已知零件怎么拆装；原论文不把重力、抓取和机器人操作约束全部纳入规划。当前简单平移式爆炸动画不能代替这个环节。
- [DYNAMO](https://arxiv.org/abs/2509.12430)（2025-09 预印本）从分割 CAD 点云预测耦合运动；MechBench 含 693 个合成齿轮装配。比独立门铰链更接近传动，但轨迹预测不是经过加载验证的接触力学模型。
- [Gen-Mech](https://jl6017.github.io/GenMech/)（NeurIPS 2025 Creative AI Track）通过共享潜空间 VAE 关联目标轨迹与平面连杆图像；[LinkD](https://arxiv.org/abs/2601.04054)（2026-01 预印本）用自回归 Transformer 与扩散模型生成连杆拓扑和关节坐标，展示到 20 节点机构。它们针对运动要求设计机构，不辨认某辆自行车实际采用的结构。

近期两个基准也能帮助理解精度边界。[OmniMech](https://arxiv.org/abs/2608.05539)（2026-08 预印本）使用带尺寸与公差的工业图纸，报告模型仍难可靠落实细节和公差；[OmniCAD](https://arxiv.org/abs/2608.22637)（2026-08 预印本）包含 25k 装配体、平均 12 个零件及 21 种配合关系，报告位置、配合、穿插与复杂度增加带来的困难。论文摘要中的“将开源”不能视为已核验数据下载和可复现运行。

**对本仓库的直接含义**

目前仓库的爆炸图支线属于“带图像证据的程序化分件建模”，并未完成精密 CAD 逆向工程。蓝色内部件是待检验候选；暂定辐条和链节数需要独立核对。原有链传动物理资产则证明了特定夹具和输入下的功能，两者应保持独立证据。

后续优先读 FunCAD-Harness 的测试绑定与等效机构限制、AssemCAD 的 ports/mates 表示，以及 Procedura 的逐件构建接口。再把现有 Artisan/Isaac 流程用于机器人任务验证。对不可见结构，保存多个合理候选，并根据近拍、型号资料、拆解或主动操作证据逐步排除；不能靠增加网格数量宣称完成识别。

本次没有安装这些外部项目或下载模型。SPADA 全文读取失败，因此只纳入官方摘要层面的结论；其余具体数值均注明原文位置。没有找到完整解决方案是此次检索结论，不是对所有未公开研究的断言。
