# EnvCreator：用于机器人操作的物理资产要求

本约定补充现有生成、装配语义与工具验证流程。对象按任务需要提供交互能力；装饰背景不要求承受操作。本文是生成与交付要求，不表示所有条款已有自动检查器。

## 生成入口与证据

`harness/run.py` 组织感知、范围、资料、蓝图、几何、验证与交付。`construction/design.py` 记录零件及连接假设；`harness/geometry.py` 和受信任 Blender worker 生成几何，Artisan 导出通用刚体资产。特定工具通过注册实现构建与验证，目前公开工具入口为 `envcreator tool` / `envcreator tool-test`。

明确文本设计可直接使用带来源标注的参数化生成器，不必伪造图像感知或 VLM 调用。三角盒试验的 `tools/triangular_box.py` 复用 EnvCreator 的 Blender backend，直接装配 USD；该实验入口尚未注册到通用 CLI，也没有经过 Artisan 导出。

每个交付版本保存原始要求、来源、假设与未知项、参数及单位、代码/资产哈希、模拟器版本、验证协议、前后状态和失败修订。工程推测不标成实测，引用的拧紧力矩不标成松脱力矩。运行中的已识别版本不更改；修改后另建版本。

## 机械资产必要条件

| 内容 | 资产与运行时必须说明或实现的行为 | 必要的验证 |
|---|---|---|
| 部件与通道 | 可分离件为独立刚体；孔、槽、承压面及工具通道实际存在，碰撞几何保留功能空腔 | 重载后的几何/碰撞检查，插入与干涉对照 |
| 工具匹配 | 刀头形状、尺寸、槽深、间隙、坐标系与 TCP 有来源；扭矩/转速单位一致 | 匹配刀头能传动；错尺寸、未插入和错轴不能传动 |
| 接触与承压 | 刀头端面、槽口与孔底存在单向接触；压紧力有来源和作用点；不能以几何深度或力阈值开关冒充接触过程 | 接触前无凭空反力；压入有反力；抬起释放；作用与反作用成对 |
| 啮合与失啮 | 插入、承压、相位、扭转顺应性与传扭上限有明确含义；区分六角、一字和十字，不能统一假设相同顶出规律 | 正常啮合传扭；相位不合/未就位的搜索与接触行为；退出后不残留虚拟扭矩 |
| 螺纹连接 | 直径、螺距/导程、旋向、有效长度与导程角一致；松脱、运行、退出分别建模 | 转角与轴向位移吻合；不足力矩、停机、直接提拉不得错误解除 |
| 顶盖与夹紧件 | 螺丝头、被夹件和螺纹座有承压关系；预紧力是否实际存在明确记录 | 顶盖受约束与解除后的自由度符合连接状态；不能把状态名当成实际预紧力 |
| 反作用力 | 电机反扭矩→外壳→夹具/腕部；刀头→螺丝→螺纹座/盒体；顶盖与支承接触均传力，力矩按作用点搬运 | 自由/固定支座对比、载荷守恒与运动响应；多个连接的外力不得覆盖彼此 |
| 稳定工件 | 不默认焊死工件；桌面摩擦、质量、惯量、接触材料有假设与范围 | 未按压与按压对比；理想按压力、夹具与机器人左手按压分别标注 |
| 数值行为 | 真实量级力矩下求解稳定；接触偏置、碰撞分块、步长与求解器设置保留 | 停机时稳定、无初始穿透/弹飞；工作载荷有限；必要时步长敏感性检查 |
| 完成状态 | 螺纹退出、零件分离、停机、保持/释放分别有物理依据 | 不依赖模型自述或电机空转；保持原始轨迹/状态证据 |

螺丝刀的轴向保持力与左手对盒体的按压力是不同的载荷路径。没有实际传感与接触验证时，不指定某个固定压力为普适真实值。先做载荷范围实验，再依据硬件标定。

固定支架、腕部固连、磁吸、理想导向和数学螺纹都可用于早期实验，但必须出现在交付假设中。未实现真实夹紧预载、真实螺牙、真实抓持时不能宣称已验证这些能力。

## 当前三角盒试验

要求为边长约 30 cm 的等边三角盒、独立顶盖与三角部螺丝；高 8 cm、壁/盖厚 4 mm、质量与摩擦为设计假设。使用 M4×0.7、8 mm 有效啮合长度、3 N·m 工具的独立参数版本。

截至 2026-10-30 的开发记录：
- 参数化几何、开孔、角部螺纹座与 USD 装配已生成；顶盖、盒体和三颗螺丝是独立动态刚体。
- 力学计算测试与理想轴线 PhysX 台架已验证旋出及反例；不代表机器人试验通过。
- `native_screw_runtime` 已实现移动支座坐标、按作用点搬运的反力、三紧固件载荷汇总，以及单向轴向接触。刀头插入后的两个槽壁接触站点同时产生横向力与抗倾斜力矩，退出后取消；不使用位姿对齐伺服冒充接触。
- 早期碰撞分块和 D6 导向配置失败保留在各版本目录。v6 实际盒体台架中，50 N 理想压盖载荷下可传递约 2.02 N·m，约 24.8 s 后旋出 8 mm 螺纹；未压盖工况盒体转动并失啮。50 N 是台架外载，不是机器人左手验证。
- 实际拔出仍在验证：`full-removal` 与 `full-removal-v2` 都在螺纹退出后倾斜卡孔，未完整取出。`full-removal-v3` 补齐槽壁作用力矩后依旧未取出。隔离诊断发现顶盖部分烘焙凸包侵入孔内；局部毫米坐标烘焙后短拔出台架通过；v7 完整拔出但初态偏移不合格，v8 修正最小厚度的物理单位，停机 callback 台架偏移约 0.004 mm。v8 锁外步前施力版本的完整台架已通过：峰值 2.007 N·m，约 24.85 s 退出螺纹，约 30.30 s 达到 24 mm 分离；其他两颗仍连接。原生 callback 内直接解除 USD 导向会触发互斥锁错误，已改为求解步前解除。不得用“thread_clear”冒充“removed”。
- 螺纹内的横移/倾斜采用求解器原生导向，螺纹退出时解除。3 N 磁吸是有上限的理想保持力；没有真实螺牙、夹紧预载或真实手指抓持。
- 实际预紧力、螺丝质量/惯量、材料摩擦和真机传感仍未标定。机器人首轮已建立左手接触，采样按压力峰值约 13.6 N，但未完成有效啮合和拆卸；因断电主轴转速异常由原生 Astra 急停。被动阻尼修订已通过独立停转台架，联合机器人验证未完成。右腕反作用及三颗螺丝完整取出仍未验证。

## 理想观测与后续迁移

当前优先修复物理资产；保留理想几何真值和测量，不在本轮提前删减观测接口。每轮另行记录 Agent 实际可见的图像、关节量、接触/力矩量、精确几何误差和内部状态。

可分阶段使用：
1. 理想观测下探索工具使用与双手协作，记录实际调用、生成控制程序、失败和物理结果。
2. 在同一环境中传递可复用的方法与经验，再用受限观测重新执行；旧真值坐标不能充当新一轮识别结果。
3. 硬件具备对应接口后，再测试真实视觉、编码器、腕部力矩/估计、电机电流等信号。仅图像的条件与带力觉的条件分别报告。

传递会话上下文是经验复用；策略/模型参数没有优化时，不称为训练。若后续训练策略，要保留其训练数据、参数版本与实际优化记录。理想环境成功不直接证明受限观测或真机成功；这部分以后单独实现和验证。

## 接触耦合回归要求（2026-10-30 v9 修订）

- 独立后向欧拉或静摩擦计算的预测速度不等于 PhysX 接触求解后的实际速度。若摩擦/螺纹在外部求解，必须包含持续小扰动、接触阻挡、移动支承的长时对照；不能仅用自由单体积分自洽测试准入。
- 预紧力要由真实施加载荷和盖板接触反力共同核验；“设计2500N”不等于实际测得2500N。材料密度、几何体积、质心、主惯量及主轴方向一并交付。
- 螺纹解除必须验证六自由度恢复。仅关闭 articulation 关节或看到轴向移动，不能证明螺丝成为自由刚体；需要解除后的横向运动/转动及刚体句柄有效性对照。
- 关节、接触和电机的反力来源分别标注；原生约束反力不再以重复外力补偿。构成关系估计值不得伪称为传感器测量。
- 停机测试包含运动外壳和初始主轴转速；直接提拉测试分别明确工件固定、左手按压与完全自由条件，避免把整件举起误判为螺纹失效。
