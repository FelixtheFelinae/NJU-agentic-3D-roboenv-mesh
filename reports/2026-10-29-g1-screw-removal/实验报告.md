# G1 使用固定电动螺丝刀拆卸螺丝：实验记录

实验时间：2026 年 10 月 28 日晚至 29 日凌晨（北京时间）。

本次在 Isaac Sim 中，由 ClawSpine 原生 DSH 调用 G1 控制工具，完成了目标螺丝的反转、螺纹脱扣和离孔提起。螺丝最后仍由理想磁性批头保持；后续左手接近和剥取尝试没有完成证据。结果适用于当前简化力学模型，不能等同于真实螺纹拆卸或真实抓持成功。

## 1. 环境与调用流程

EnvCreator 提供电动螺丝刀资产、目标螺丝、固定支撑和桌面场景。螺丝刀通过固定关节安装在 G1 右腕，不要求手指抓取，也不要求按实体开关；电机由显式工具命令启动。

ClawSpine 原生 DSH 使用 `gpt-6-astra`，负责读取相机、关节、雅可比及开放的工具仪表读数，编写局部控制程序并执行。运行中所有 280 条模型生成消息均标记为 Astra，没有使用 Qwen 进行任务控制。本轮没有重新调用 VLM、SAM 或 3DGS 生成资产；这些重建环节不参与实时控制。

实际调用关系如下：

```text
EnvCreator 场景与工具资产
  → ClawSpine 原生 DSH / Astra
      → read_camera / read_whole_body_state / read_power_tool
      → Agent 编写 align.mjs，后改为 tip_servo.py 局部控制
      → register_low_reflex / execute_low_reflex / execute_whole_body
      → command_power_tool 启停、反转
  → Isaac / PhysX 每子步计算工具及螺丝受力
  → 原生会话、物理事件和相机帧记录
```

`src/roboenv_perception/tools/native_screw_runtime.py` 将工具和螺丝的实时物理状态接到力学模型；`screwdriving.py` 判定批头啮合并传递相反扭矩；`fastener.py` 计算螺纹阻力、旋转—轴向位移耦合和脱扣状态。物理步长为 1 ms，机器人控制周期为 20 ms。原生接入补丁保存在 `integrations/clawspine/native-screwdriver.patch`。

本机启动入口为：

```bash
bash outputs/g1-wrist-screwdriver-20261028/desktop/start.sh astra
```

## 2. 实际执行与结果

前期 Agent 使用“读取状态—计算关节增量—执行一段—等待停稳”的方式对准，出现关节跟踪偏差和反复失啮。随后编写原生 Low Reflex，在控制周期内根据右手掌姿态、雅可比和标定的批头偏移连续修正位置，保留关节目标并加入阻尼。电机仍通过原生接口独立控制。

低速反转期间，Agent 分段核验径向偏差、插入深度和螺丝退出量，适时上移批头。曾提高至 7 rpm 后失啮，随后恢复低速；期间也发生过失啮后的回退和重新校准。

| 北京时间 | 物理记录 | 结果 |
| --- | --- | --- |
| 10 月 28 日 22:34:33 | `clamped → loosening` | 开始出现有效拧动 |
| 10 月 29 日 00:30:25 | `loose_threaded`，退出 0.401 mm | 已松动，仍在螺纹内 |
| 02:05:05 | `thread_clear`，累计旋转 31.895 rad，退出 4.002 mm | 约 5.08 圈后解除螺纹约束 |
| 02:16:01 | `removed`，退出 18.004 mm | 提起达到分离判定距离 |
| 最后物理采样 | 退出 43.164 mm，`thread_active=false` | 螺丝已离孔，仍磁吸在批头上 |

最后采样中电机禁用，目标转速为零，实测转速约 −0.080 rpm。左手已接近并尝试合拢手指，但尚无可靠接触、剥离或接住螺丝的证据。最后一轮在这一阶段因模型连接错误结束。

这不是一次不间断自主完成的试验：过程中有人工续跑消息、模型服务错误和配置调整；上下文窗口从 131,072 调整为 1,000,000 tokens。该记录用于展示功能可执行性，不用于统计单次成功率。仿真累计推进约 521.6 秒，现实时间跨越约 5 小时 22 分钟，二者不能当作同一种任务耗时。

## 4. 当前螺纹仿真

### 尺寸与力学参数

| 项目 | 当前设定 |
| --- | --- |
| 螺杆外形 | 直径 4 mm、长 10 mm 的光滑圆柱 |
| 有效螺纹啮合长度 | 4 mm |
| 导程 | 0.8 mm/圈，假定单线螺纹，约 5 圈脱扣 |
| 初始起拧阻力 / 运行阻力 | 0.002 / 0.0008 N·m，均为假设值 |
| 旋转—轴向耦合 | 弹簧阻尼跟踪 `z = pθ/(2π)`，刚度 2000 N/m、阻尼 5 N·s/m |
| 横向约束 | 固定孔轴周围的弹簧阻尼，刚度 500 N/m、阻尼 2 N·s/m |
| 批头 / 内六角槽对边 | 3.0 / 3.1 mm |
| 啮合条件 | 径向偏差 ≤50 μm、倾角 ≤3°、插入 0.5–2.5 mm；重新进入要求六角相位偏差 ≤3° |
| 传扭 | 弹性扭转与阻尼，传递扭矩限制 0.02 N·m |
| 电机 | 隐式限矩速度驱动，接口限制 ±30 rpm、最大 0.2 N·m |
| 离孔提起 | 脱扣后由最大 3 N 的理想磁性弹簧阻尼力保持，偏离超过 15 mm 失效 |

螺纹仍有效时，模型根据旋转和轴向退出量提供耦合力与阻力矩，并通过横向弹簧和抗倾斜力矩维持孔轴附近的位置。累计旋转对应退出量达到 4 mm、实际退出也达到 4 mm 后，解除螺纹约束。之后实际上提超过 18 mm，记录为 `removed`。

批头与螺丝间对应的真实碰撞被排除，由几何门限和相反扭矩替代。力学运行组件不直接写入螺丝姿态或角度；本次局部控制程序根据观测返回机器人关节目标。

### 已验证的范围

此前同一运行组件的理想移动台架测试中，对准时可拧出并提起；横向偏位、倾斜、悬空、尺寸参数不匹配和电机关闭五组对照未拧松。错尺寸对照检验的是语义门限，没有另建不同尺寸槽的接触几何。

本次进一步验证了 G1 右腕固连工具可以在上述模型中，通过 Agent 编写的局部控制完成脱扣和提起。尚未验证手指抓持工具、真实螺纹接触、不同初始条件下的稳定成功率或真实硬件迁移。

### 不足与本轮暴露的问题

1. **螺纹是软约束，没有真实导向接触。** 横向位置、倾斜和导程关系都靠弹簧阻尼维持，没有孔壁、牙型或螺纹侧面的实际接触。误差、回退与参数和步长有关，不能当作真实螺纹行为。
2. **插入后的批头缺少槽壁约束。** 当前门限负责判断和切断传扭，却没有提供足够的侧向支撑、入口倒角和自导向。50 μm 门限与 G1 的晃动叠加后，容易突然失啮；重新进入时还需恢复六角相位。此次多次出现几十微米级偏差引起传扭中断。
3. **连接参数未经实物标定。** 螺距、啮合长度、阻力矩、质量和间隙都是实验假设，尚未对应已识别规格；没有预紧力、夹紧件压缩、摩擦随载荷变化、螺纹损伤或卡死模型。
4. **磁吸只模拟平移保持。** 它是理想弹簧阻尼力，不模拟磁场、接触摩擦或可靠的姿态保持。脱扣后螺丝可以相对批头倾斜；“磁吸开启”也不等于仍满足六角啮合。
5. **状态机主要覆盖单向拆卸。** `removed` 是达到过分离阈值后的状态，不是每时刻都重新判定的实时距离条件。当前不能据此宣称支持重新插入、旋紧和预紧力恢复。报告同时列出实际退出量，避免只凭状态标签判断。
6. **机器人与驱动仍有明显误差。** 曾出现关节目标与实测位置偏差、左臂动作导致右腕移动，以及电机禁用后短暂被动转动。禁用命令意味着进入主动制动，不保证转速瞬间为零；需要继续读取转速和连接状态。
7. **任务调度成本较高。** 前期反复读取大块状态、逐段停稳和上下文压缩占用大量时间。后期局部控制改善了跟踪，但模型断线和人工续跑仍使实验过程不连续。

## 5. 后续修改

优先把螺纹内的孔轴与导程关系改为稳定的约束表达；批头正确插入后建立带间隙和柔顺性的局部导向，按拔出、明显倾斜或过载解除，避免只靠瞬时位置门限切断。保持插入前的几何检查，不增加远距离自动吸附。

随后用固定台架和机器人固连工具分别验证导程、脱扣、拔出限制、失啮与过载对照，再重复当前任务。左手剥取单独验证接触和抓持，不并入本轮已经确认的拆卸结果。
