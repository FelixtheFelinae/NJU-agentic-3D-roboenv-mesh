# 三角盒的物理修订与验证（v9）

本轮修复从 `g1-astra-one-screw-bearing-20261030` 的异常现场开始。旧会话、末态、源代码哈希与三路录像已保留；没有在失败现场直接覆盖资产，也没有继续提交付费 Agent 任务。

## 原因与代码修改

原 `tools/fastener.py` 在 PhysX 接触求解之外独立计算螺纹和静摩擦。该计算预测的零速度并不能约束随后由接触产生的运动，因而未操作的螺丝也会累计旋转。轴向受阻并持续施加 0.0006 N·m 扰动的隔离实验复现了这一机制。它说明求解耦合缺陷，不等于已经逐项还原现场所有接触冲量。

`tools/solver_thread.py` 将导程关系交给 PhysX articulation 内的 prismatic/revolute mimic 约束：`z = θ × 0.7 mm / 2π`。物理螺丝是独立刚体，通过可解除的连接附着在导程机构上；退出后解除连接，保留真实的横移和倾斜自由度。直接删除 articulation 内部关节不能可靠恢复六自由度，这一失败方案没有采用。

有界摩擦使用原生关节弹性滑移模型：小位移时提供静态阻力，达到力矩上限后更新滑移位置。它与接触一起求解，避免外部摩擦计算遗漏接触冲量。纯速度阻尼仍会产生缓慢漂移，已放弃。每颗螺丝保留两个 1 g、惯量 1e−7 kg·m² 的无碰撞数值辅助刚体；连接期间存在额外惯量，拆下后的螺丝质量与惯量按真实几何计算。这是明确的数值正则化，不是额外实体零件。

已通过几何匹配而插入的刀头使用原生横向间隙、有限摆角和孔底单向限制；沿轴向退出不锁定。工具与螺丝的扭转耦合具有 3 N·m 上限。磁吸仍为上限 3 N 的理想保持模型。

`tools/native_screw_runtime.py` 汇总各紧固件对盒体和工具的作用力，按作用点搬运力矩。电机参数只修改主轴自由度，保留机器人或测试滑台的其他关节设置。原生约束已产生的反力不再重复施加外力。

## 盒子与预紧模型

`experiments/triangular_box/build_v9.py` 复用 EnvCreator 已生成的 Blender 几何，重新计算体积、质心、主惯量与材料质量，输出 USD 和 `mass-properties.json`。本轮是用户指定尺寸的参数化设计，没有调用 VLM 或伪称从视频识别材料。

| 项目 | 采用值与含义 |
|---|---|
| 外形 | 300 mm 等边三角形，高 80 mm，壁和盖厚 4 mm |
| 盒体 / 顶盖 | 铝材密度 2700 kg/m³；质量约 1.334 / 0.420 kg |
| 螺丝 | 钢材密度 7850 kg/m³；约 2.973 g/颗；外观为 M4 类内六角，不声明完整符合 ISO 4762 |
| 螺纹 | M4×0.7，单线，8 mm 有效啮合，约 11.43 圈退出；节径约 3.545 mm，导程角约 3.60° |
| 初始预紧 | 2500 N/颗，在 40 μm 等效松退距离内释放 |
| 摩擦假设 | 螺纹及头下等效摩擦系数 0.14；头下等效摩擦半径 3 mm；空载运行阻力 0.005 N·m |
| 工具 | 原资产 3 N·m 上限；日常命令限速仍为 30 rpm；加速台架单独放开到 120 rpm |

预紧采用简化的螺栓—被夹件模型：向盖板施加向下的夹紧力，在盒体相同世界作用点施加反力；另将储存弹性势能的松退力矩 `F × lead / 2π` 成对作用于螺丝和盒体。夹紧力确实参与求解。头下预紧摩擦与螺纹摩擦合并为作用于螺丝/盒体的阻力，未分别解析头下接触应力与盖板扭矩分布。

这避免把几千牛预紧力直接通过数值较脆弱的小质量外部连接传递。螺栓内部弹性应力、盒盖弯曲、螺纹牙接触、铝材螺纹剥离均未解析；40 μm 是设计假设，不是材料标定结果。

采用的摩擦模型给出约 1.49 N·m 初始松脱力矩。Bossard 的 M4、8.8 级资料给出约 2.3–3.3 N·m 的最大装配力矩、4.3–4.6 kN 最大预紧参考；这些是装配参考，不能当作本盒子的实测松脱力矩。资料及 PDF 位于 `reports/2026-10-30-screw-physics-audit/`，本轮参数与引用位于 v9 的 `sources.json`。

## 实际验证

测试运行在本机 Arena 镜像中的 Isaac/PhysX，采用 CPU TGS，常规步长 1 ms。完整原始轨迹、失败候选、代码和资产哈希保存在 `outputs/triangular-box-20261030-v9/`。

- 12 s 变载扰动：10/30 N 压盖、水平力、倾覆力矩和未操作螺丝上的小扭矩；没有累计自转或错误解除。稳定段最大角度变化约 0.072°，最大导程残差约 11.5 μm。
- 0.5 ms 时间步长对照：保持连接，最大导程残差约 4.3 μm；盖板—盒体法向接触载荷保持在约 7.5 kN 量级。
- 固定盒体后直接提拉 20 N，或施加不足以松脱的 0.3 N·m：三颗螺丝均保持连接。最大导程残差约 45.5 μm，是数值柔度，不能解释成实测螺栓伸长。
- 缓慢增加已知外加扭矩：约 1.487 N·m 时检测到明显松转，与所采用参数的计算值一致；这是仿真台架结果，尚无实物标定。
- 独立解除连接测试：螺丝能够上移、横移和倾斜，排除“状态已解除但仍被关节限制”的问题。该测试人为解除连接，只验证拓扑，不冒充完整拆卸。
- 完整工具旋出/拔出：最终版完整工具台架通过：8 mm 螺纹退出后，轴向分离达到 32.52 mm；另外两颗角度约 0.016°，保持夹紧。最大导程残差约 7.0 μm；最终断电主轴约 −0.067 rpm。日志没有引擎错误。原生主轴/外壳关节分别测得峰值反扭矩 1.3020015 / 1.3020017 N·m，旋出过程中轴向承压约 1.18 N。结果见 `validation/acceptance.json`。第一次 120 rpm 台架出现退出后倾斜卡孔；后续完整拔出分支又在日志审核中发现 PhysX 拒绝无限上界，不能作为最终验收。两轮均保留，最终版改用有限上界并重新完整测试。

无外加压盖的 4 s 对照也保持了啮合并开始松转：理想工具滑台自身通过刀头侧向约束提供稳定作用，因此这一台架不能证明“必须有左手按压”。台架的固定工具滑台和 50 N 外加压盖载荷不代表 G1 右手或左手已经验证。几何门控、磁吸保持、数学螺纹属于理想化工具模型。当前不宣称真机定量等效，也不把会话上下文复用称为训练。盒盖采用刚体，故预紧力正确施加也不能证明真实铝盖的变形、密封或强度合格。

## 使用入口

- 生成：`experiments/triangular_box/build_v9.py --source outputs/triangular-box-20261030-v8 --output <新目录> --pretension 2500`。
- 载荷测试：`experiments/triangular_box/validate_native.py --asset <USD> --output <JSON> --case perturb --seconds 12`；另支持 `pull`、`torque`、`breakaway`、`release`。
- 完整工具台架：`experiments/triangular_box/validate_tool.py --asset <盒子USD> --tool <螺丝刀USD> --output <JSON> --seconds 40 --rpm 30 --press 50`。
- 场景组合：`experiments/triangular_box/compose_v9.py`，将新盒子装入现有桌面和腕部工具的 G1 场景。

生成需要 USD Python 绑定；物理测试需要 Arena 内的 IsaacLab，不可用普通 Python 编译成功代替物理验证。后续先验证最终组合场景的 G1 接触与反作用，再考虑真实硬件摩擦、预紧和传感标定。

## 本地框架接入

本地 RoboHelix 的 `playground/tools/vla_isaac/docker/` 同步了 `native_screw_runtime.py`、`screwdriving.py` 与新增 `solver_thread.py`。`scripts/launch_dsh_sim.mjs` 的运行时快照清单包含新模块，避免新会话缺失导程求解依赖。相关快照测试 8 项通过。没有修改旧会话快照、模型、凭据，也没有向 GitHub 推送。

Python 力学与接口回归 25 项通过。系统 ROS 自动加载的 pytest 插件与项目虚拟环境不兼容，测试使用 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1` 运行；这不涉及仿真器驱动。
